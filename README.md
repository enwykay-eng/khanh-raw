# Khánh Nguyễn Raw – portfolio

Static site (index.html + p/ + logob/ + img/). No build step.

Deploy: Netlify > Add new site > Deploy manually (kéo thả thư mục/zip), hoặc push lên GitHub rồi Import project (Publish directory: `.`).

Video showroom Việt Thương: copy file vào `video/viet-thuong-showroom.mp4`, rồi trong index.html đổi
`video:{mp4:"",link:""}` của sự kiện "viet-thuong-showroom" thành `video:{mp4:"video/viet-thuong-showroom.mp4",link:""}`.
(File >12MB, GitHub web upload tối đa 25MB nên vẫn up được.)
